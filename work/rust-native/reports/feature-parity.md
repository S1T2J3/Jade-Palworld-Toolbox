# Jade Rust 原生迁移功能验收基线

基线：已发布 v1.0.17。此表描述既有行为，不代表 Rust 版本已经实现。发布前逐项记录测试结果与证据；仅显示同名标签、列表或数量不能算通过。

## 总体与数据

- 所有界面/计算/存档读取使用 Rust 原生代码；不得将 C#、Go、Gecko、前端 JS 外包执行而称全原生。
- 保留 25 个最终加工数据表和 1592 个图片。最终表包括 build.cjs 注入的掉落、商店、任务、设施、地图、图鉴相互关联，不能只读取未加工原始 JSON。
- 保留 12942 个地图源点、300 个物种、2466 个物品、5110 条全局搜索记录；基线计数按构建输出重验。
- 新版本须与稳定版独立安装/数据目录/更新通道；不可将 prerelease 提供给稳定版自动更新。
- 中文名称/中文输入法、中文路径、鼠标/键盘、缩放和窗口尺寸均可用；下拉框必须能选中。
- 所有长列表可访问全部结果；后台/虚拟化不能截断数据。

## 共用导航与窗口

- 左栏全部分区/顶部二级页面均可到达；在小窗口可展开导航。
- 返回回到实际上一窗口/页面，保存路由、筛选和滚动位置；前进与 Alt+左右可用。
- 图鉴跨项跳转保留对应对象；地图跳转可返回原物品/手记/任务。
- 最小化、最大化、关闭与皮肤整合；单实例再次启动激活现有窗口；Ctrl+N 新窗口。
- Ctrl+K 全局搜索：中文/英文/编号、NFKC、分类型过滤、完整结果/更多、方向键/Enter/Escape；结果精确跳转对应详情。
- 数据说明、来源和原外部资源链接仍可查看/外部浏览器打开。

## 配种手册

### 配种查询
- 中文/英文/编号筛选并选择全部物种；默认选中和头像/属性一致。
- 查配种伙伴和反查双亲；伙伴/子代检索、子代属性过滤、每页数量/全部、密集多列结果。
- 亲代/伙伴/子代点击更换查询目标；加入仓库打开个体编辑；刷新位置跳转正确物种。

### 配种仓库
- 一物种可多只、每只稳定 ID；头像名称上方、词条下方，姓名、雄/雌/未记录。
- 添加、编辑、移除/归档、搜索/筛选和完整个体列表；游戏未知物种/词条仍保留。
- 词条最多四个、稀有度从高到低及等级图标；全部词条视图不用分页、搜索可用。
- 世界独立、数据落盘、重启保留、跨窗口变更同步；写入失败不悄悄丢数据。

### 可配子代
- 根据有效仓库个体计算全部能配物种；几步以内筛选，搜索/属性过滤。
- 查看子代路径和所需亲代，跳转配种查询/图鉴/刷新位置；已失去个体不能出现在路径。

### 目标配种
- 目标列表完整；选择 0 至 4 词条，显示稀有度/图标；允许随机词条、使用已得手术台词条开关。
- 计算必须考虑不同个体、性别、实际拥有词条和合法配方；不能把同种不同个体的词条直接合并。
- 已有目标个体仍可计算新孵化路径；只有没有可用配种路径时显示相应原因。
- 手术台可以提供的词条不能标为随机孵化；混合随机/手术路径正确。
- 路径步骤、代数、源亲代、手术位置/消耗/价格、缺失项、无法到达原因、建议补充亲代可读。
- 新建/保存/选择/删除配种计划；记录每步实际孵化结果并加入仓库、恢复进度和完成目标；失败/库存变化使过时结果失效。
- 刷新现有帕鲁直接重新扫描读取关联世界，不需重复手点世界档案；状态/禁用/错误可见。

## 世界档案与存档读取

- 新建、切换、重命名、删除（确认）、当前世界统计、关联/解除游戏世界、按游戏名称更新档案。
- 自动扫描 Steam 与 Xbox/Game Pass WGS、手选存档目录、记忆有效目录；默认目录存在但未找到世界时提供该目录。
- 支持旧/新存档、PlZ1/PlZ2/PlM1、CNK 多分块、中文路径、世界名称；正在写入的快照拒绝混用。
- 读取本人的终端和携带队伍，无法判断时选一次玩家并记住；可主动更换玩家。
- 姓名/性别/词条/个体 UUID 来自游戏；重复读取不重复；缺失个体归档并退出配种；重现恢复同 UUID。
- 空扫描/异常/部分解析不能清空仓库；手动个体、其他玩家/世界不受影响；原始游戏存档只读、测试前后 SHA 一致。
- 全部/当前世界 JSON 导出；导入预览再建独立世界、名字去重；格式无效/重复ID/额度失败原子回退。
- 兼容 `pal-atlas-worlds` version 1，保留 inventory records/archived/removed/limit、surgery、plans、mapNotes。
- 原稳定版资料可通过备份迁移；原 profile 不写坏、不复用测试版 schema。

## 世界地图

### 地图点位
- 两个地图区域切换、底图、官方类别图标、首领各自头像、矿种区分；全部类别可选/全选/清空/展开。
- 拖动、滚轮锚点缩放、放大缩小/全图、键盘方向/加减/Home、缩放读数；聚类可展开/放大。
- 名称/类别搜索、完整匹配列表、点位选中定位、悬停等级范围、详情/坐标。
- 完成复选、全部/完成/未完成过滤，世界独立持久化；自定义点位鼠标选坐标或手输、名称备注、编辑删除、完成状态。
- 地图详情跳转敌人、商人、物品、任务、奖励表、手记、生产；按 point/category/coords 三种路由定位。
- 大量点位和低倍率拖动没有明显拖影；隐藏页面停止无用绘制。

### 帕鲁刷新位置
- 全部物种搜索选择、白天/夜晚及适用区域过滤、地图分布、点位/等级范围、列表/定位。
- 右侧物种属性/特性、编号/头像、详情和配种跳转；从目标配种/图鉴进入保持物种。

## 帕鲁图鉴

- 编号/中文/英文搜索、元素/工作等原有筛选、完整物种卡片、选择详情。
- 头像、属性、基础值、工作适应、技能/伙伴、食量、掉落、出没、配种/工作/物品/商人关联可点击。

## 单位图鉴

- 敌人、商人、其他中立单位三页各自搜索/类别过滤、完整列表和详情。
- 敌人属性/等级/掉落数量概率、初次奖励/召唤材料、关联帕鲁/任务、地图点位可跳转。
- 商人售卖和购买物品、价格/币种、任务奖励、多个位置坐标；点击选定位置才定位。
- 中立单位请求/奖励、关联物品与地图；与物品图鉴两向关联。

## 帕鲁详情

- 主动技能：名称/元素等过滤，威力/冷却/学会方式/适用帕鲁详情，关联物种与技能果实。
- 被动技能：名称搜索/等级筛选、稀有度高到低、游戏等级图标、效果、固定携带帕鲁。
- 伙伴技能：默认编号排序、头像、战斗/工作等用户筛选、技能等级效果、解锁装备/物品、对应帕鲁跳转。
- 技能果实：完整技能果实/技能关系、效果和物品详情、获取/地图关联。
- 帕鲁手术台：全部可获得词条、操作模式/消耗/费用、已获得复选并按世界保存，目标配种勾选后使用这些词条。
- 属性值计算：选物种、等级、个体值、强化/浓缩等原输入、四词条和训练开关；面板/远征属性/力量实时计算。
- 捕捉概率：物种/等级、剩余生命、球种、捕捉力、世界倍率、异常等输入，准星/实际概率与不可捕捉边界正确，关联球/刷新地点。

## 帕鲁工作

- 工作适应性：按各工作类型筛选、等级高到低、暗系标记；帕鲁头像/详情/工作效率链接。
- 设施：名称/工作/类别过滤、等级/材料/产出/工作要求，关联物品/据点生产。
- 据点生产：生产设施/工具、原料消耗/产量/时间、工作条件、产物/配方/设施/地图关联。
- 工作效率：手选或选择仓库个体、物种、工种、适应性等级、词条组合；等级基础值/工作/牧场/搬运效果拆分并输出数值。
- 牧场产物：按帕鲁或物品入口、伙伴技能等级/掉落范围等信息；物品、帕鲁、伙伴技能两向跳转。
- 遗物转换：输入类型/等级/数量等原控件、可出物品、概率/数量/转换花费，物品两向跳转。
- 远征所：不同远征要求、适合属性/工作、难度/时间/条件、可能奖励及数量/概率，物品和相关资料跳转。

## 物品图鉴

- 中文/英文/ID、类别/属性等过滤、全部结果分页/继续加载、选中详情、图片、描述、属性。
- 获取来源：野外采集、牧场、遗物、远征、敌人/中立单位、任务、奖励表、商店、地图，全部已有内部关联都可点。
- 商人子页按币种/价格显示；单商人可直接定位，多个商人显示坐标供选择。
- 制造配方/设施/解锁/原料数量、作为原料用途；点击原料/产物切换详情。
- 合成路径：输入目标数量、在多配方中选择来源、递归展开生产步骤、外部材料汇总、循环依赖提示，数量调整实时生效。
- 饰品遗迹图纸点击定位对应远古遗迹。

## 冒险指南

- 属性克制：清晰游戏风格关系图，属性选择/相关说明与图鉴关联。
- 异常状态：搜索/选择、效果和来源、关联技能/物品/属性。
- 野外采集：搜索/过滤、采集工具/要求/产出、矿种区分、物品/设施/地图类别定位。
- 探索奖励表：章节/子表/条件、概率数量、完整物品，物品和地图关联。
- 任务详情：章节/任务选择、前置/目标/完成奖励，目标物品/单位/点位全部可跳转。
- 探索手记：全部正文、作者/编号搜索、详情、原出处、对应地图点位。

## 设置、公告与更新

- 辉月伊和普通配色可选，关闭重启保留；图标/背景与标题栏同步。
- 公告完整列表、未读数、弹窗设置与显示；新更新公告 popup=true，弹出即已阅。
- 测试更新源与稳定源分开；检查更新、自动下载开关、下载进度、错误/重试、SHA验证。
- 自动下载选择增量可用则增量，否则全量；下载完成询问立即重启或下次启动；两条安装路径均验证。
- 损坏包/安装失败回退旧程序；并发窗口/重复启动/失败网络不能破坏数据。

## 公平延迟测量

- 同一 467 个体公共备份，同机器、窗口、数据和地图分类；版本交替运行至少 5 次，报告中位数和范围。
- 启动结束必须是首屏内容已呈现且能接收操作，不能只算 main() 或窗口创建。
- 分别记录首次安装/首次数据目录、暖启动、初次打开/预加载后地图、搜索、目标配种、物品详情、读档、拖动帧时间和峰值内存。
- UI 操作结束条件为正确内容实际渲染；所有测试先验证内容结果和存档数量。
- CPU 节流只标为模拟，不能当真实低配机结果；不保证没有实测的收益。

独立审查找到并修复：任务只有 `site` 坐标时无法定位；奖池缺少地图/远征/遗物反向关联；野采缺少生产和完整点位链接；图鉴工作缺少各工种效率入口；终端导入创建世界先于持久化；玩家归属混用；目标查询与伙伴查询共用目标状态；计划中断事件不恢复；实际手术没有记录入口；页面下方计划/归档被长列表挡住；词条没有搜索；可配子代缺少不限步数与按世界记忆。

另外向根任务指出并由根任务处理：`#guide/loot/{chapter}/item/{item}` 深链接未选择奖池、图鉴工作筛选/排序、工作排行榜指定帕鲁的路由、预加载地图超出显卡纹理尺寸上限。以上项目应以根任务随后执行的测试和最终截图为准，不能仅根据本清单认定完成。

测试使用公开样本及临时生成的世界资料，没有访问用户真实游戏存档。低配置显卡/CPU 的真实表现、整套安装与更新重启、所有长页面和返回位置的实际操作，仍需结合最终性能/安装报告判断；静态链接检查只证明目标存在，不能单独证明每个鼠标点击位置正确。
