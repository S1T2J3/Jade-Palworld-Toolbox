# Rust beta.8 · 地图持续加载与物品效果验证

地图使用同一个后台工作线程。首页先出现，固定约1.2秒后继续加载帕洛斯群岛和世界树；提前进入任一地图会唤醒同一任务。鼠标移动、导航和最小化不再重置等待或丢弃结果。完成后不再解码，提前打开则先画内置512px预览，后台完成后替换清晰纹理。缩放、聚类层级、筛选、刷新位置和用户标注沿用原实现。大底图遵守GPU纹理尺寸上限，串行解码及有界队列限制峰值占用。

## 本机实测

同一公开测试档案，467只帕鲁、12942个点位。独立Win32桌面实际GPU截图，无用户游戏存档访问。以下为单次本机对比，不能代表不同电脑或真实显示器端到端延迟。

| 项目 | beta.7 | beta.8 |
|---|---:|---:|
| 启动到第二次UI绘制 | 425ms | 375ms |
| 帕洛斯底图后台完成（UI探针起点） | 1389ms | 1385ms |
| 世界树底图后台完成（UI探针起点） | 未预载 | 1581ms |
| 首次进入世界树页面到资料/底图可用 | 274ms | 48ms |

限制进程至两颗逻辑处理器：默认图1468ms、世界树1752ms完成，世界树页面46ms可用。仅限制同一台电脑的CPU调度，未模拟慢磁盘或旧显卡。启动指标会有波动；此次改动重点是持续预载和避免黑屏，而非承诺所有电脑的首页启动时间下降。

故意为每张底图增加1000ms延迟后，首张GPU截图中的完整底图尚未完成，但预览与点位已显示；随后当前页面自动显示清晰底图。两张图分别在2240ms和3491ms完成。截图已人工检查。1440×900与960×620窗口检查装备、饰品、食物、技能果实及蛋糕详情，效果区正常换行并可滚动。

## 物品效果

2466个物品按精确编号加入效果数据，其中915个装备/武器/滑翔伞/模块等原始条目保留各自数值。包含防御、生命、攻击、耐久、弹匣、负重、营养、SAN、捕获力、装备被动和食物持续时间；植入体显示对应词条效果并跳转手术台，技能果实跳转对应主动技能。既有配方、商人、掉落、遗迹、获取途径与合成路径仍保留。

原始数值取自[固定游戏数据提交](https://github.com/Dhampyru/Palworld-Extracted/tree/d38105b4dc0cf6f36c5035997fbe54205bb2d753/Pal/Content/Pal/DataTable)。中文用途与效果名称来自[PalDB物品表](https://paldb.cc/cn/Items)，另核对25个具体资料页，链接和原始输入摘要保存在item-effects-data.json与item-effects-extra.json。更新内容离线提供，运行时不需要联网抓取。未公开的特殊/测试条目仍明确说明缺少资料；Otomo_MoveSpeed_up_1的特殊效果未确认，未把内部枚举或未经确认单位当作百分比。

## 功能检查

109项检查通过，包括102项应用测试、1项核心回归集合（1942个案例）和6项公开存档夹具检查。另针对最终物品数据验证普通/传说装备数值、食物增益、所有物品编号及关联物品/技能存在，并以原生指针点击确认技能果实和吸血鬼植入体跳转。测试中467条仓库记录、地图标注内容哈希均保持一致。

安装包与文件增量包验证结果随本次发行的验证JSON记录。测试不会运行安装向导或修改真实游戏存档。
