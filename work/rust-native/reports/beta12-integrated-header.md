# Rust beta.12 · 顶部窗口栏融入界面

移除单独的35像素标题栏，将最小化、最大化/还原和关闭按钮放进58像素页面工具栏的右侧，与当前皮肤使用同一套颜色。左侧保留Jade标志与工具箱名称；原有返回、前进、公告、编辑草稿和页签继续使用。

工具栏先为三个窗口按钮预留138像素，再为拖动区预留40像素，其余空间用于页面操作和横向滚动页签。内容区域裁剪到各自范围，960×620窗口也不会用页签覆盖关闭按钮。按钮悬停采用皮肤选中色，关闭保持红色提示。

左上Jade品牌区域与顶部小点区域可以拖动窗口，双击可最大化/还原，拖动命中不覆盖页签或功能按钮。沿用beta.11的Windows原生四边、四角缩放与圆角。窗口按钮使用独立的界面层，世界档案或更新弹窗打开时仍可使用，同时保持弹窗下方的普通页面不可点击。

## 检查

141项应用测试和1项核心回归集合通过，核心集合包含1942个案例。新增测试用实际指针事件检查关闭、最大化、还原、最小化、拖动和双击命令；另检查不同绘制顺序下，窗口按钮能越过弹窗工作，而底下的页签不会收到点击。进入靠右的页签或缩窄工具栏时立即滚入选中项，用户随后手动横向滚动不会被持续拉回。

实际窗口查看辉月伊和青玉皮肤，以及世界档案弹窗场景，覆盖默认窗口和最小960×620窗口。直接向实际程序的egui输入队列注入指针点击，确认新位置的最大化按钮改变了原生窗口状态；还原、最小化、关闭和弹窗层级通过组件的实际指针测试核对。另用独立原生窗口探针检查四边四角命中、原生缩放、最大化还原、负坐标与圆角。

私有桌面上的Posted WM鼠标消息未能可靠驱动按钮，此诊断方法不作为按钮验证的成功证据；有效结果来自上述直接事件注入、组件测试和原生几何探针。

另外查看1440×900、960×620窗口的配种、七页签的帕鲁详情和工作、公告、地图和编辑草稿，核对新工具栏布局及返回/前进操作。所有检查使用同一份公开467只帕鲁档案，不读取真实游戏存档；仓库和地图标注内容哈希保持一致。

发布包逐个核对文件哈希，并验证增量包复原与四种实际更新流程。游戏资料和图片资源不变。安装向导未运行；通过解包和隔离测试窗口检查，未修改安装注册和快捷方式。二进制、安装包哈希与具体结果见同名JSON。
