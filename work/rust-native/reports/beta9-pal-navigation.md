# Rust beta.9 · 帕鲁资料与跳转验证

帕鲁名称和头像统一进入完整宽度的帕鲁图鉴详情。页首可选择地图与刷新位置、查配种伙伴、反查双亲、目标配种、属性值计算和捕捉概率。所有入口自动带入当前物种，原有技能、工作、掉落、商人等关联仍保留。

配种结果三位成员、仓库成员、可配子代的父母和子代、配种路线、实际执行记录、地图详情、刷新位置侧栏、伙伴技能列表、计算器及工作资料的帕鲁身份入口保持一致。明确标注的功能按钮保留直达；帕鲁选择器和牧场左侧的筛选选择仍执行选择操作。伙伴技能卡片的名称/头像打开帕鲁资料，技能行和卡片其它区域仍可打开伙伴技能详情。可配子代新增明确的「配种路线」按钮，保留路线弹窗。

## 返回与上下文

跳转前记录配种查询的当前物种与查伙伴/反查双亲模式；返回和前进使用同一套激活逻辑。进入新的物种或模式时重置该查询的页码和选择框搜索文字，物品/工作/地图等其它导航沿用原机制。

原生窗口实测点击路线：

1. 查伙伴 Anubis → 结果子代 HoodGhost 的资料。
2. HoodGhost 资料 → 刷新地图 → 返回 HoodGhost 资料 → 返回 Anubis 查伙伴。
3. Anubis 资料 → Anubis 反查双亲 → 返回资料 → 返回 Anubis 反查双亲。
4. Anubis 资料 → 目标配种（实际界面选中 Anubis）→ 返回资料 → Anubis 查伙伴。
5. 可配子代 → 明确的配种路线按钮 → 完整父母、性别及子代路线弹窗。

## 检查范围

105项应用测试和1项核心回归集合通过；核心集合包含1942个案例。新增原生指针测试检查配种结果中亲代/伙伴/子代的头像和名称、伙伴技能卡片的身份入口与技能入口，以及资料页的六个功能按钮。

实际GPU窗口检查九个页面：资料、查伙伴、反查双亲、仓库、伙伴技能、刷新位置、可配子代、牧场反查、捕捉计算。另检查960×620小窗口的资料、反查和可配子代。完整资料页、按钮排布、配种路线弹窗已人工查看截图。

全部窗口检查使用同一份公开467只帕鲁测试档案，未读取真实游戏存档。仓库记录和地图标注内容哈希保持一致。原数据表与图片资源不改变，地图持续加载方式沿用beta.8。安装包和增量文件的验证结果记录在对应JSON中。
