# Rust beta.13 · 游戏悬浮窗

在「设置 → 游戏悬浮窗」开启后，保持工具箱运行，切回幻兽帕鲁的无边框或窗口模式，按Alt+J呼出完整工具箱，再按一次收起。快捷键可改为Ctrl+Shift+J、F8、F9；可以选择切换到其他应用后自动收起。首次默认关闭，旧档案无需迁移。

悬浮模式使用同一个Rust窗口和当前世界记录，地图、配种、图鉴、仓库、筛选与导航均保留。左侧提供「返回游戏」和「回到桌面」；悬浮会话中的右上角关闭按钮用于收起，普通窗口的关闭按钮和系统Alt+F4继续退出。修改后的记录在悬浮会话中及时保存，收起前再次保存待写入数据。

## 窗口行为

通过系统的 [RegisterHotKey](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-registerhotkey) 和独立窗口回调处理快捷键，使用 [SetWindowPos](https://learn.microsoft.com/en-us/windows/win32/api/winuser/nf-winuser-setwindowpos) 调整当前工具箱窗口的置顶和位置。识别前台进程的可执行文件名，只接受帕鲁Win64/WinGDK Shipping客户端；不修改游戏文件，不安装MOD，也不读取游戏进程内存。

进入时保存普通窗口的位置、大小、最大化及置顶状态，返回普通窗口时恢复。悬浮窗在游戏客户区内显示，游戏窗口小于960×620逻辑最小尺寸时使用所在屏幕的工作区；两者都放不下时显示状态说明，不强行缩小内容。

主动收起才归还游戏焦点；切到其他应用时不抢回焦点，属于工具箱自己的文件对话框也不会触发误收起。游戏在后台退出时保持隐藏，保留恢复信息，下一次快捷键或普通窗口激活后恢复，避免打断当前应用。再次进入有效游戏会重建退出检测。退出检测仅在会话中使用每秒一次的原生计时器，没有新进程或常驻轮询线程；默认关闭时不注册快捷键和事件回调。

回调只持有独立状态，不保存App裸指针。禁用时释放快捷键并恢复普通窗口，销毁时解绑；解绑失败时保留已禁用回调的独立引用直到窗口销毁。全局快捷键冲突会明确显示，不会取消其他程序的注册。

## 验证与实际游戏范围

149项常规应用测试和1项核心回归集合通过，核心集合含1942个案例；另外单独执行1项私有桌面原生会话测试，共151项成功检查。原生测试创建两扇真正的Windows测试窗口，通过模块内部接口模拟游戏目标，覆盖置顶、隐藏、重新显示、窗口位置与最大化/最小化恢复、外部激活、隐藏后的游戏退出不抢焦及重新进入后计时器工作。测试入口仅存在于测试代码，没有正式程序假游戏句柄入口。

发布程序另检查默认关闭、设置持久化、真实RegisterHotKey冲突与退出释放、旧档兼容、最小窗口和原有页面。全部使用公开467只帕鲁测试档案，仓库和地图标注哈希不变。安装包逐个核对文件哈希，并验证增量复原及立即更新、下次启动更新、失败恢复、多窗口保护；游戏资料和图片资源不变。安装向导未执行，未修改安装注册和快捷方式。

**当前环境没有运行中的真实帕鲁进程，因此尚未实测真实局内兼容性、鼠标捕获表现或游戏帧率。**窗口替身和快捷键测试不能替代这部分验证。本版是首个游戏悬浮窗测试版，优先供无边框/窗口模式试用，不保证独占全屏显示。具体二进制哈希和测试记录见同名JSON报告。
