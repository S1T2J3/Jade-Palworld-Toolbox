# Rust beta.10 · 返回与前进体验验证

返回和前进现在恢复离开时的页面状态：搜索、筛选、排序、分页、滚动位置，配种查询的物种、模式和目标词条，计算器的目标与输入，以及地图视角、筛选和选中点。历史使用实际显示的物种和功能地址，重复点击当前功能不会制造空历史，也不会清掉前进记录。

返回先关闭当前下拉框、搜索或临时窗口，再返回上一页。未保存的帕鲁个体编辑和地图点位编辑可暂存，使用「继续编辑」恢复；切换世界后不会恢复其它世界的编辑。前进按钮固定位置，悬停可查看目的地，右键可选择最近历史；支持 Alt+左右方向键和鼠标前后侧键。输入文字时 Backspace 继续用于删字。

历史最多保留64条轻量视图记录，不复制仓库、地图数据、图片缓存、计算结果或后台任务。返回不撤销实际保存的仓库、世界档案和地图标记。恢复配种输入时，已失效的计算会按当前仓库重新计算，不使用过去的帕鲁副本。不同世界的状态不会相互覆盖。

## 自动化检查

发布配置下134项应用测试和1项核心回归集合通过，核心集合包含1942个案例。检查包含历史容量和顺序、连续相同地址、前进记录、菜单跨步返回、实际滚动惯性清除、计算目标与输入恢复、弹层优先关闭、编辑草稿、世界隔离，以及既有配种和地图行为。两份未保存草稿同时存在时，按钮、侧键、快捷键和历史菜单不能越过正在编辑的窗口跳页。

未优化的调试配置中，既有地图解码测试曾触及5秒期限；已隔离另一个测试不必要启动的后台地图加载。请求地图的单独调试测试通过，最终完整检查使用实际发布配置通过，原5秒期限未放宽。存档解析代码没有修改，需要外部研究语料的可选测试未在此次重新运行。
