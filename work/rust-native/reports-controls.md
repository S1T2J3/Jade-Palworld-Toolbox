# Rust 2.0.0-beta.4 原版界面与交互图标核对

本次以正式版 v1.0.17 的实际窗口为参照，逐项处理用户指出的遗漏。界面仍由 Rust 原生绘制。

| 用户指出的项目 | 本次处理 |
| --- | --- |
| 上侧栏 | 恢复渐变背景、带图标页签、选中下划线、返回/前进和公告未读徽标；小窗口使用紧凑间距，切换页面时自动显示当前页签。 |
| 公告界面 | 恢复公告与更新双卡，小窗口上下排列；支持展开正文、展开即已阅、全部已读、弹窗偏好、重新弹窗查看和更新操作。随包历史公告现在离线也可查看，迟到本地资料不会覆盖已获取的远端公告。 |
| 牧场产物 | 恢复按帕鲁/按材料的图片查询和反查、产出数量与概率、等级选择、图鉴跳转。修复卡片文字遮挡点击区域的实际问题。 |
| 工作适应性 | 使用 12 种原版彩色工作图，按等级从高到低分组显示帕鲁头像；保留搜索、属性筛选、暗属性月牙、效率计算及图鉴跳转。 |
| 主动技能图标 | 列表、详情及搜索统一使用对应属性的真实 SVG，并按属性着色；属性小标签也补回图形。 |
| 被动技能图标 | 官方 24×24 等级纹理按方形显示；2/3 阶金色、4/5 阶青色、负阶珊瑚色并向下翻转。图标本身也可勾选词条或进入详情。 |
| 帕鲁手术台图标 | 恢复真实手术台、性转药图片、建造材料与关联跳转；手术词条使用正确等级图。 |
| 可配子代图标 | 每个组合补齐两位亲代头像、子代头像和真实箭头；保留完整路线入口。 |
| 右上角关闭图标 | 最小化、最大化/还原、关闭使用矢量图形和独立点击区域；关闭悬停变红。窗口拖动区域避开三个控制按钮。 |
| 其他可点击图标 | 统一常用添加、编辑、删除、保存、刷新、分页、返回和弹窗关闭按钮；复选框恢复方形，避免看起来像单选框。 |

## 验证

最终完整回归：74 项应用检查、1 项核心对照检查和显式启用的 6 项公共存档检查，共 81 项通过。核心对照检查覆盖 1,942 个计算用例。

新增检查实际解码了 52 个矢量图标，验证窗口控制与弹窗关闭的独立点击区域、词条图片的实际绘制尺寸/等级颜色/负向 UV、点击等级图勾选、公告展开及自动已阅、公告弹窗偏好、本地与远端公告初始化顺序，以及牧场和工作适应性图文卡片的真实指针操作。没有用“成功生成截图”代替这些交互检查。

使用真实原生窗口检查默认 1440×900 和 960×620 两种尺寸。逐页对照配种页、公告、牧场正查/反查、工作适应性、主动技能、被动技能、手术台、可配子代和仓库。小窗口专门检查了顶部页签、筛选按钮、右侧产量表、四词条卡片及分页；公告弹窗另检查正文、已阅状态与关闭入口。

所有窗口检查使用公开的 467 只帕鲁档案，长昵称和四词条仅在临时测试副本中构造。样本 SHA-256 为 `5f7af3f4534da06920bac3eb28524b5db5adbcfd5980c953c0f377054f6c2e6c`。检查库存及地图记录前后哈希不变，未读写真实游戏存档。
