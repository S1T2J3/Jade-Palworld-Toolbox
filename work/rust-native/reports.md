# Rust 原生测试版 2.0.0-beta.1 验收与延迟

测试日期：2026-11-11。基线为已发布的 Gecko v1.0.17，候选为 Rust 原生界面、计算、存档读取、地图与更新。两版使用同一份公开测试档案，467 只帕鲁；没有读取或修改用户真实游戏存档。

## 测量结果

Windows 11，Ryzen 9 9950X3D，RTX 5090，约 32 GB 内存。已完成安装与首次档案初始化，各版本预热一次后交替运行 5 轮，下表为中位数。资料、默认地图分类及仓库一致。地图在首页静置 5 秒后打开。

| 项目 | 正式版 v1.0.17 | Rust beta.1 |
|---|---:|---:|
| 首屏界面准备 | 605.2 ms | 342.5 ms |
| 首次进入地图 | 284.0 ms | 52.5 ms |
| 限制 2 个逻辑核心：首屏准备 | 1051.2 ms | 357.7 ms |
| 限制 2 个逻辑核心：进入地图 | 436.0 ms | 63.6 ms |
| 批量可配子代计算 | 17.17 ms | 5.49 ms |
| 四词条阿努比斯目标计算 | 6.81 ms | 3.14 ms |
| 已有棉悠悠，再孵化一只 | 2.53 ms | 2.41 ms |

首屏“准备”记录界面构建检查点，不等于屏幕已经显示的时刻。Gecko 使用首屏内容后的动画帧，Rust 使用第二次界面更新；由于渲染架构不同，不能把这一项的约 43% 差值视为严格同口径的屏幕呈现加速率。另行确认 Rust 首屏 GPU 截图回调上界为 512.7 ms，2 核限制下为 364.4 ms，包含截图回读和事件派发成本；Gecko 下一动画帧为 610.2 / 1055.2 ms，两者端点不同，不计算其百分比。

地图进入等待在本机约减少 82%，两核限制下约减少 85%。4 倍缩放各记录 450 个拖动帧，Rust 每帧界面 CPU 耗时中位 0.967 / 1.046 ms，各轮 P95 的中位 1.520 / 1.456 ms。这个 CPU 时间不等于完整显示帧时间；隐藏测试桌面的刷新节奏也不能直接当作真实显示器帧率。每轮拖动前后截图确认地图实际移动，地图标记与仓库哈希保持不变。

后三项仅测进程内算法：2 次预热、5 次采样，JS 与 Rust 完整结果逐字段一致；不含文件解析、跨线程传输、界面绘制或程序启动。批量子代与四词条目标分别约减少 68% 和 54%；轻量棉悠悠案例接近持平。

2 核测试是在同一台高配置电脑上限制进程调度范围，已核对实际进程掩码为 0x3。它不模拟旧显卡、慢硬盘或少内存，不能代表所有低配置电脑。图形驱动最低需支持 OpenGL 2.0；目前没有软件渲染备用方案。

## 功能与文件验证

- 25 个原始加工资料表与 1601 个原始资源文件保持一致，另加入原版词条等级贴图；300 种帕鲁、44552 条配方、2466 件物品、12942 个地图源点完整。
- 5110 个搜索入口、8064 个内嵌内部链接及额外生成的任务、物品、采集、生产、奖池关联均检查有效目标。静态目标检查不等于每一个鼠标位置都经过人工点击。
- 全部 51 项产品测试执行通过，其中一个核心测试包含 1942 组原版算法对照案例；公开存档的额外测试也显式执行通过。
- Steam、服务器目录、Xbox WGS、旧新压缩与 CNK、多玩家、携带队伍、终端个体、重复刷新、丢弃归档、备份与多窗口冲突处理均有回归；游戏文件校验前后保持一致。
- 世界档案、真实配种路径、图鉴、商店坐标、手记全文、牧场、计算器和地图经原生窗口截图检查；自定义点保存、完成、修改、删除使用实际控件输入验证。
- 立即安装、下次启动安装、损坏程序回退、其他窗口仍运行时阻止安装四种实际更新流程通过，467 只仓库记录保留；增量复用、路径和哈希校验通过。
- 安装包、ZIP、目录中的 2124 个文件 path/size/SHA256 一致，清单自洽。从安装包提取的实际程序在只有 Windows 系统目录的 PATH 下运行，未依赖本机 Rust、LLVM 或其他开发运行时。
- 安装器本身通过编译与解包验证；没有在用户系统执行注册、快捷方式或卸载流程。测试版独立安装、独立数据、独立公告和更新通道，稳定版 v1.0.17 保持为 Latest。
