# Native save-reader sources

- Vendored `uesave`: https://github.com/oMaN-Rod/uesave-rs, commit `75f9c2405725ec417448791b04939d819ad0d286`, branch `pluggable-game-support`; MIT license retained in `vendor/uesave/LICENSE`. Only the library source is included. Cargo metadata is standalone and the C++ Oodle feature/dependency is omitted; Jade performs read-only decompression with the pure Rust `oozextract` crate. Local compatibility change: `PalCharacterData.trailing_bytes` retains the actual byte length, including the omitted tail in legacy saves; the corresponding optional JSON conversion is adjusted.
- Palworld property layout/access patterns were studied in PalStudio, https://github.com/oMaN-Rod/palstudio, commit `69213343cbc42abeef8e68b249efad655f17649a` (GPL-3.0-only), and the existing Jade `palworld-save-reader` integration (GPL-3.0-or-later). This adapter is released under GPL-3.0-only; it exposes no save-writing API.
- Public fixtures in `work/terminal-import/parser/research` belong to their original test-data contributors, documented by the existing research checks. They are never substituted for or read from the user's real SaveGames directory in tests.
