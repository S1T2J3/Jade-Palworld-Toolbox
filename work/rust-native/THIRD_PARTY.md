The decompressor source is also bundled in the source archive under source-dependencies.

Original data attributions are retained in the source repository THIRD_PARTY.md and data tables, and available from the application data notices. The software license does not grant rights to game assets.

Compiled with Rust 1.99.1 (MIT/Apache-2.0) and LLVM-MinGW UCRT 20261104; Windows system DLLs are provided by Windows, not downloaded by this app. Chinese fonts are read from the installed Windows fonts and are not redistributed.
