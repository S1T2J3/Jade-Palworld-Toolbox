# Rust 2.0.0-beta.3 界面与地图修复报告

## 本次修复

地图原来按屏幕坐标分格。平移让同一批点位反复拆合，分组代表和绘制顺序也跟着变化；部分普通地点还混合不同类别，因此图标前后遮挡会跳变。

现改为按地图本地坐标聚类，同类分别成组、成员按固定 ID 排序，组按固定类别顺序绘制。缩放时仍允许聚类拆合，单纯平移不会改变分组。边缘按整格裁剪，组的代表、中心和计数不随成员出入视野闪动。资源位于目的地点位下方，选中点单独置顶。重叠点位保留列表选择，聚类放大、点位详情、完成标记、自定义点位及关联跳转继续可用。

界面修复：

- 图片来源共用同一套查找逻辑，图鉴列表、全局搜索和详情保持一致。补接敌人帕鲁头像、主动技能属性图、技能果实、被动词条等级图、野外采集物、据点生产物和手记分类图。
- 工作效率页的词条选项与已选词条补上等级图片，可点击已选词条进入详情；保留四词条上限和移除操作。
- 四词条和长昵称的仓库卡片曾达到 312 像素，但虚拟列表按 232 像素计算行位置，造成跳行和截断。现压紧行距并省略过长昵称，卡片符合预留行高，悬停可查看完整昵称；同时为底部分页预留空间。
- 搜索结果固定行高、文字左对齐，名称和说明过长时省略，悬停可查看全文。补上其他图鉴类型的搜索缩略图。
- 属性克制图按原图 1200×675 的比例显示。

## 验证方法

完整工作区的 62 项应用检查、1 项核心检查及显式启用的 6 项公共存档检查均通过；最终地图修改后另运行全部 11 项地图检查，包含新增的跨类别重叠指针检查。按不重复的检查计数共 70 项通过。核心对照测试覆盖 1,942 个计算用例。针对本次问题新增了平移聚类稳定性、边缘完整分组、仓库四词条长昵称行高、工作词条选择上限与移除、图片解析和解码等检查；跨类别重叠检查验证打开全部点位列表、逐项选择、关联路线及选中层级。

真实窗口检查使用公开的 467 只帕鲁档案，并在临时档案中构造四词条长昵称及重叠自定义点位，未改动真实游戏存档。公开样本 SHA-256 为 `5f7af3f4534da06920bac3eb28524b5db5adbcfd5980c953c0f377054f6c2e6c`。每次检查均核验库存和地图记录前后哈希不变；构造的数据只保存在临时测试目录。

已检查默认窗口及 960×620 小窗口、仓库滚动和分页、工作效率词条勾选、全局搜索到帕鲁图鉴的跳转、补图后的图鉴列表和详情。帕洛斯全分类地图、世界树全分类地图及帕鲁刷新位置各连续拖动 90 帧，检查地图确有移动、资料加载无错误、记录保留。此处为功能回归，不将单次并行运行的 CPU 时间称作端到端延迟或性能提升。

自动检查和抽样窗口检查不能覆盖每台电脑、每份存档或所有点击顺序。程序依然使用 Rust 原生界面，运行条件与 beta.2 相同。
