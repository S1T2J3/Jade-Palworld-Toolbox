# Jade 幻兽帕鲁工具箱 · Rust 原生版

Windows x64 原生桌面应用。界面、配种与计算器、存档读取、地图、备份和更新均由 Rust 实现；运行时不启动 Gecko、Chromium、JavaScript、Go 或 C# 进程。界面使用 eframe/egui + OpenGL。

## 使用

运行本版本的 `-Setup.exe` 安装包，或解压 Windows ZIP 后运行 `Jade-Palworld-Rust.exe`。保留相邻的 `data` 目录。安装与离线资料查询均可断网使用。

beta.2 按 v1.0.17 恢复窄侧栏、图标与辉月伊配色，配种/仓库的密集卡片和分页，以及图鉴详情、原版筛选和关联跳转。地图恢复侧栏筛选、浮动点位详情和档案弹窗；计算器分别记忆输入。仍使用 Rust 原生界面，保留后台预加载和长列表虚拟化。

Rust 版沿用 Rust 测试版的安装标识和数据目录 `%LOCALAPPDATA%\JadePalworldRustBeta`，直接安装 2.0.0 可继续使用测试版的仓库和设置。从 1.x 版迁移工具箱记录时，在旧版的世界档案导出 JSON，然后在 Rust 版的世界档案导入并确认预览。Rust 版也支持只读扫描游戏存档。

界面支持 Ctrl+K 打开「搜索与问答」、Alt+左/右返回与前进、Ctrl+N 新窗口。地图支持拖动、滚轮、方向键和缩放按钮。默认再次启动激活已有窗口。

### 帕鲁助手与可选内核

安装包和便携包都自带全局搜索与基础问答。点左侧「搜索与问答」或按 Ctrl+K，在同一个框里输入名称、编号、别名或完整问题。输入「蛋糕」能看匹配条目，可用方向键选择后按回车打开。输入「蛋糕怎么合成」按回车或点「问助手」，即可查看图鉴配方。发送后输入框清空。离开再打开，或再次按 Ctrl+K，会开始空白会话。基础问答在工具箱进程内运行。

需要连续追问、仓库顾问或 AI 时，另取与工具箱完整版本号相同的 `Jade-Pal-Assistant-Kernel-…-windows-x64.zip`。在「设置 → 帕鲁助手」点击「导入内核包」，直接选 ZIP。工具箱会核对版本和文件摘要，通过后启用。点「停用内核」即可回到基础问答，点「启用内核」可以再次使用。内核保存在工具箱的用户数据目录。更新工具箱后，请使用新版本配套的内核包。

启用内核后，可以接着蛋糕配方问「那做十二个呢」，或问「我仓库里哪两只能配出阿努比斯」。离线内核会查询本地资料及当前世界的工具箱记录。这些功能无需安装大语言模型。

查图鉴时可以指定要比较的方面，例如「冰刺鼠和唤冬兽冷却工作谁更快」「机械弓设计图 4 怎么获得」「唤冬兽的伙伴技能是什么」。回答附带对应的图鉴入口。资料中有物品来源但没有各路线耗时时，获取途径可供比较，实际刷取速度仍取决于玩家条件。

要用生成模型讨论开放问题，内核提供以下入口。

- 在助手里启用「免费云端 DeepSeek」，输入硅基流动中国站个人 API Key，然后提问。工具箱把本轮问题、工具箱查询结果及最多两轮最近对话发给硅基流动，云端回答显示在原问题下。仓库查询结果可能包含当前个体的信息。密钥只在本次会话中使用。平台要求实名认证，模型受账号限流约束。当前接入的免费模型是 DeepSeek-R1-0528-Qwen3-8B。[模型定价](https://www.siliconflow.cn/models/deepseek-ai%2FDeepSeek-R1-0528-Qwen3-8B) · [免费模型使用条件](https://docs.siliconflow.cn/docs/userguide/faqs/rate-limit-and-upgradation)
- 使用 ChatGPT 或 DeepSeek 的网页账号时，在某条问题下点「用免费网页版问」。可以预览和编辑要带过去的内容，再复制到官网发送。把网页回答粘贴回来并确认，它就会显示在对应问题下，也能带入下一次追问。
- 已安装 Ollama 的玩家可以选择「本机 Ollama」，使用自己的本地模型进行分析。

2.0.0 起，Rust 正式版从 `rust-v...` 正式发行版检查更新。打开自动下载后，有适用的文件增量包时优先使用增量，其余情况下载完整包。下载验证后可立即安装并重启，也可在下次启动时安装。失败会保留或恢复上一版。从旧 Rust 测试版迁移到 2.0.0 使用安装包或便携包。

## 配置范围

Windows 10/11 x64，显卡驱动需支持 OpenGL 2.0 或更高。没有独立浏览器或额外下载运行时的要求。图片按需解码，资料与两张地图在首页可用后持续准备；纹理大小服从设备上限。CPU 核心限制测试仅是模拟，不能代替真实旧电脑测试。Windows 基本显示驱动仅提供 OpenGL 1.1 时可能无法打开，需安装显卡厂商驱动。

## 从源码构建

推荐 Rust 1.99.1，`x86_64-pc-windows-gnu` 目标与 LLVM-MinGW UCRT；让 `llvm-windres` 可从 PATH 找到。中文路径下使用 LLVM 的链接器：

```powershell
$env:RUSTFLAGS='-C linker=rust-lld.exe -C linker-flavor=ld.lld'
node work/build.cjs --desktop build/rust-data-source
node work/rust-native/export-data.cjs build/rust-data-source
cargo build --release --locked --manifest-path work/rust-native/Cargo.toml
```

Node 仅用于开发时把现有经过关联处理的资料转换为 JSON；最终应用不需要 Node。将编译产物与生成的 `data` 放在同一目录即可运行。使用 Inno Setup 6 可构建独立安装包：

```powershell
pwsh -File work/rust-native/package.ps1 -InnoCompiler 'C:\Path\To\ISCC.exe'
```

`Cargo.lock` 锁定依赖版本。`cargo test --workspace --locked --manifest-path work/rust-native/Cargo.toml` 运行核心与 UI 状态测试；需要 Windows 常规桌面权限的本地互斥锁/文件替换测试不应在禁止这些 API 的隔离环境运行。存档公共样本测试另见 `crates/jade-saves/README.md`；测试不能依赖用户真实世界。
