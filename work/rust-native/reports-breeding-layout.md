# Rust beta.7：完整配种组合

“查配种伙伴”原来每组只显示伙伴和子代，本次改为：**当前亲代 + 配种伙伴 → 子代**。当前选定的帕鲁固定出现在每组最左侧，带原头像、名称和图鉴编号。

保留多列布局、文字/属性筛选、每页数量、分页及名称进入刷新位置的操作。特殊配方的两位亲代分别标注所需性别；即使当前帕鲁在原始配方的第二侧，也按正确性别显示。“反查双亲”的原有显示和操作保留。

验证：9 项配种状态/交互回归和 1 项核心对照通过；核心对照包含 1,942 个原版计算用例。实际窗口检查 1440×900、960×620、反查双亲，以及两种特殊配方亲代顺序；另实际点击当前亲代、伙伴、子代，确认分别进入对应帕鲁的刷新页。

窗口检查使用公开的 467 只帕鲁档案副本，库存和地图记录前后哈希一致，没有读写真实游戏存档。QQ 交流群：1126734443。
