    扫描位置与提示

      备份与恢复

      备份包含仓库个体、归档、手术台标记、配种计划、已完成的地图点位和自定义点位。导入会创建独立副本，游戏存档可在本机重新关联。

      从旧 Windows 版或浏览器版迁移
      1. 打开原来使用的手册，进入「世界档案」，选择「全部世界」并导出 JSON 备份。
      2. 回到独立版选择备份，核对个体、手术标记与计划数量，点击「导入为新世界」。
      旧窗口里的仓库为空？

      请切换到原先使用的浏览器和个人资料。旧 Windows 版页面位于 %LOCALAPPDATA%\PalBreedingAtlas\index.html。使用 HTML 版时，请在原浏览器中打开原路径下的 HTML 文件。
